College Transport Information Portal 🚌

📌 Project Description

The College Transport Information Portal is a web-based application developed to help college students easily access transportation information. Students can view college bus routes, pickup points, and morning and evening bus timings in one place.

The main aim of this project is to make transportation information simple, accessible, and user-friendly.

🎯 Objectives

- Provide college bus route information.
- Display student pickup points.
- Show morning and evening bus timings.
- Help students find suitable bus routes.
- Save students' time and reduce confusion.

✨ Features

- Home Page
- Bus Routes Information
- Pickup Points
- Bus Timings
- Search Function
- Mobile Responsive Design
- Contact Information

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
